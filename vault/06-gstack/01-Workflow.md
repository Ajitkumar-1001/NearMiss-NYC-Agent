# gstack Workflow

How review skills are used during the build.

| Stage | Skill | Note |
|---|---|---|
| Product sanity | `/plan-ceo-review` | [[02-Product-Review]] |
| Engineering sanity | `/plan-eng-review` | [[03-Engineering-Review]] |
| Design pass | `/design-review` | [[04-Design-Review]] |
| QA sweep | `/qa` | [[05-QA-Checklist]] |

## When to run each

- **Before building:** product + engineering review on the plan
- **Mid-build:** design review once the UI is real enough to judge
- **Before demo:** QA sweep against [[05-Demo-Reliability]]
